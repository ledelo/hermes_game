# Hermes — 자율 수익 에이전트

**미션**: 2026-08-12 ~ 2026-08-26 (2주) 동안 사용자 개입 최소화로 순수익 ₩1,000,000 달성 시도.

**채널**: 네이버 스마트스토어 위탁판매 (도매꾹 소싱, Leviosa MCP 운영)

**구조**:
- `ops/PLAYBOOK.md` — 에이전트 운영 규칙 (상태머신 + 가드레일). 매 웨이크마다 이 문서가 기준.
- `ops/state.json` — 기계가 읽는 현재 상태 (단계, 등록 상품, 타임스탬프)
- `ops/LAUNCH_QUEUE.md` — 선별된 등록 대기 상품 (점수·마진·재고)
- `ops/ledger.csv` — KPI 원장 (일별 매출/순익 추적)
- `ops/journal/` — 일별 운영 일지

**루프**: Claude Code Remote 트리거가 매시간 이 세션을 깨워 PLAYBOOK 상태머신을 1회 실행한다.
모든 상태 변경은 이 브랜치(`claude/autonomous-revenue-agent-bxoqos`)에 커밋/푸시되어 컨테이너 재생성에도 살아남는다.

**단 하나의 수동 단계**: ① 최초 1회 네이버 스토어 연동(OAuth), ② 주문 발생 시 도매꾹 결제(사용자 지갑에서 돈이 나가는 행위).
이 둘은 계정/결제 권한 문제로 에이전트가 대신할 수 없으며, 에이전트가 알림으로 정확한 실행 목록을 제공한다.
