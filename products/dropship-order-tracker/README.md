# 위탁판매 주문·발주 트래커 (엑셀)

**파일**: `위탁판매_발주트래커.xlsx` · **판매가(안)**: ₩7,900 · **원가**: 0원
**대상**: 도매꾹 등 도매처에서 사입 없이 위탁판매하는 스마트스토어·쿠팡 셀러

## 상품 소개 (상세페이지 카피 초안)

"주문은 들어왔는데, 이거 발주했던가?"

위탁판매는 재고가 없는 대신 **발주를 빠뜨리면 그대로 사고**입니다.
이 엑셀은 주문 1건을 1행으로 적고, 발주하면 발주일을, 운송장이 나오면 운송장번호를 채우는
세 단계만 반복하게 만든 트래커입니다. 나머지는 수식이 대신합니다.

- **오늘 발주할 것만 따로 보입니다** — 대시보드에 미발주 건수와, 그 건들을 발주하는 데 필요한 현금(도매원가+공급배송비 합계)이 한 칸에 나옵니다.
- **깜빡한 주문을 잡아줍니다** — 상태가 '신규'인 채로 지연 기준일(기본 1일)을 넘기면 발주지연 칸에 `지연!` 이 뜹니다. 기준일은 설정에서 바꿀 수 있습니다.
- **한 건당 얼마 남는지 자동 계산** — 판매가·도매원가·공급배송비를 넣으면 매출액·정산예정액·순이익이 행마다 계산됩니다.
- **수수료율은 내 조건에 맞게** — 주문관리 수수료율(기본 3.63%)과 네이버쇼핑 수수료율(기본 2%)을 설정 시트에서 수정. 네이버쇼핑 유입이 아니면 0으로 두면 계산에서 빠집니다.
- 주문 400건(4~403행) 분량 수식 내장 · 월별 12개월(2026-08~2027-07) 매출·정산·순익·건수 자동 집계
- 매크로 없는 순수 엑셀 수식 파일 (보안 경고 없이 열림, 엑셀 2010 이상)

**과장 없이 밝혀두는 범위**: 정산예정액은 *수수료율만 반영한 추정치*입니다. 실제 정산액은 결제수단·판매자 등급·프로모션·배송비 정책에 따라 달라집니다. 순이익에 광고비·포장비·부가세는 포함되지 않습니다. 쿠팡 셀러는 기본값(스마트스토어 기준) 대신 본인 카테고리 판매수수료율을 설정 시트에 직접 입력해서 쓰면 됩니다. 스토어와 자동 연동되는 기능은 없습니다 — 수기 입력 방식입니다.

### 주문트래커 열 구성 (16열)

머리글 바로 위 띠가 각 열을 언제 채우는지 알려줍니다.

| 띠 | 열 |
|---|---|
| **필수** (노란 배경) | 주문일 · 주문번호 · 수량 · 판매가(개당) · 도매원가(개당) · 공급배송비 · 상태 |
| **선택** | 상품명 · 옵션 |
| **나중입력** | 발주일 · 도매 주문번호 · 운송장번호 |
| **자동** (수식) | 매출액 · 정산예정액 · 순이익 · 발주지연 |

### 계산식

```
매출액      = 판매가(개당) × 수량
정산예정액  = 매출액 × (1 − 주문관리 수수료율 − 네이버쇼핑 수수료율)
순이익      = 정산예정액 − (도매원가(개당) × 수량 + 공급배송비)
발주지연    = 상태가 '신규' 이고 TODAY() − 주문일 ≥ 지연 기준일 이면 "지연!", 아니면 ""
발주 필요 현금 = 미발주 정산예정액 합계 − 미발주 순이익 합계   (= 도매원가×수량 + 공급배송비)
```

**설계 규칙**
- 계산은 전부 엑셀 수식. 파이썬으로 계산한 값을 써넣은 셀은 없음.
- 사용 함수 9종: `IF` `AND` `TODAY` `SUM` `SUMIFS` `COUNTIF` `COUNTIFS` `EDATE` `IFERROR` — 전부 Excel 2007 표준. `XLOOKUP`·`FILTER`·`SORT`·`UNIQUE`·`TEXTJOIN`·`IFS`·`SWITCH` 등 신함수 미사용.
- 수식 열 전부 `=IF($B4="","",...)` 빈 행 가드 (주문번호 기준). 발주지연은 주문일 공백 가드(`$A4<>""`)를 추가로 적용.
- 상태 판정과 대시보드 항목명은 설정 시트를 참조(`설정!$A$11:$A$15`) — 상태 이름을 바꾸면 드롭다운·집계·지연 판정이 함께 따라감.
- 상태 드롭다운은 이름 정의 `상태목록` (= `설정!$A$11:$A$15`) 사용.
- 월별 집계는 `SUMIFS`/`COUNTIFS` + `EDATE` 날짜 구간 방식(`">="&기준월`, `"<"&EDATE(기준월,1)`) — 보조 열 없이 동작. 시작월 1칸만 바꾸면 12개월 전체가 이동.
- 서식: 금액 `#,##0"원"`, 날짜 `yyyy-mm-dd`(월 `yyyy-mm`), 비율 `0.0%`(분수 저장), 수량 `#,##0"개"`, 주문·운송장 번호는 텍스트(`@`)로 저장해 긴 번호가 지수 표기로 깨지지 않음.
- 색상: 입력 파란 글씨(0000FF), 필수·핵심 설정 노란 배경(FFFF00), 수식 검정, 헤더 흰 글씨 + 남색 배경(1F4E79).
- 시트명에 공백 없음 (시트 간 참조 시 따옴표 불필요). 조건부 서식 미사용.
- 틀 고정: 주문트래커 `C4`(주문일·주문번호 항상 표시), 대시보드 `A3`, 공급처메모 `A4`.

## 남은 이슈

- **수기 입력 방식**입니다. 스마트스토어·쿠팡 주문을 자동으로 끌어오는 기능은 없습니다. 상세페이지에서 이 점을 명확히 밝혀야 환불 분쟁이 없습니다.
- 정산예정액은 수수료율만 반영한 추정치. 실제 정산액(결제수단별 수수료, 프로모션, 배송비 정산)과는 차이가 날 수 있음 — 사용법 시트 [5]에 명시.
- 정산예정액·순이익은 원 단위 미만 소수가 남고 표시만 반올림됩니다(예: 13,117.43 → `13,117원`). 합계는 반올림 전 값으로 계산되므로 표시값 단순 합산과 1원 이내 차이가 날 수 있음.
- 상태는 5개 고정. 행을 추가·삭제하면 이름 정의(`상태목록`)와 대시보드 참조가 어긋납니다 — 설정 시트에 경고 문구 포함.
- 주문 400건 초과 시 마지막 행 복사 + 대시보드 수식 범위 확장이 필요 (사용법 시트에 안내).
- 예시 2행(4·5행)은 배포본에 그대로 포함. 5행은 상태가 '신규'라 파일을 여는 날짜가 2026-08-13 이후면 `지연!` 이 표시됨 — 오작동이 아니라 기능 시연이며 사용법 시트 [3]에 명시했습니다.
- 조건부 서식 미사용 (지연 여부는 IF 텍스트 `지연!` 로 표시, 해당 열만 굵게).
