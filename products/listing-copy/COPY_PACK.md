### FAQ (3)

**Q1. 어디까지 만들어 주시나요?**
A. 엑셀 수식으로 동작하는 시트를 만들어 드립니다. 입력한 값으로 합계, 월별 집계, 비율, 조건에 따른 표시 같은 자동 계산을 구성해 드리고, 입력 칸과 계산 칸을 색으로 구분해 사용 안내를 함께 넣어 드립니다. 매크로와 VBA, 다른 프로그램 연동, 웹 자료 자동 수집은 제작 범위에 포함되지 않습니다.

**Q2. 얼마나 걸리나요? 수정은 몇 번 되나요?**
A. 요구사항 답변을 받은 시점부터 24~48시간 안에 전달해 드립니다. 전달 후 수정 1회가 포함되어 있으며, 처음 알려주신 요구사항 범위 안에서의 수정에 해당합니다. 요구사항 자체가 크게 바뀌는 경우에는 추가 제작으로 안내드립니다.

**Q3. 제작 시작 후 취소나 환불이 되나요?**
A. 요구사항을 회신하시기 전, 즉 제작에 착수하기 전에 말씀해 주시면 전액 환불해 드립니다. 제작이 시작된 뒤에는 「전자상거래 등에서의 소비자보호에 관한 법률」 제17조 제2항 제5호(용역 또는 디지털 콘텐츠의 제공이 개시된 경우)에 따라 단순 변심에 의한 청약철회가 제한됩니다. 다만 전달드린 파일이 합의한 요구사항과 다르게 만들어진 경우에는 수정 또는 환불로 처리해 드립니다.

### 5-A. 운영 SOP (주문 1건 처리 절차)

| 단계 | 할 일 | 기준 시간 | 완료 조건 |
|---|---|---|---|
| 1. 주문 접수 | 주문 확인 후 톡톡으로 접수 인사 + 요구사항 질문 5개 발송 (위 안내문 그대로) | 확인 후 2시간 이내 (야간 접수는 다음 날 09시) | 질문 발송 완료 |
| 2. 요구사항 수집 | 답변 수령. 빠진 항목이 있으면 그 항목만 다시 질문. 참고 파일이 오면 열어서 열 구조 확인 | 답변 대기 (미회신 시 24시간·72시간 두 차례 안내) | 5개 항목 답변 확보 → **납기 시계 시작** |
| 3. 범위 판정 | 기본형 범위(5-B) 안인지 확인. 범위를 넘으면 추가 금액과 사유를 안내하고 동의 여부 확인. 제외 범위(5-C) 요청이면 대안 제시 또는 전액 환불 | 답변 수령 후 2시간 이내 | 고객이 범위·금액에 동의 |
| 4. 제작 | 순수 엑셀 수식으로 시트 구성. 입력 칸(파란 글씨)·필수 칸(노란 배경)·계산 칸(검정) 색상 규칙 적용, 사용법 안내 시트 포함 | 납기 시계 기준 24~48시간 내 | 파일 완성 |
| 5. 검수 | 재계산 실행해 오류 0 확인. 요구사항 5개 항목과 하나씩 대조. 빈 행 가드·예시 1행 동작 확인. 파일명·시트명 정리 | 전달 전 | 오류 0 + 요구사항 대조표 통과 |
| 6. 전달 | 톡톡으로 파일(또는 다운로드 링크) 전달. 사용 시작 3단계와 수정 1회 안내 동봉 | 납기 내 | 고객 수령 확인 |
| 7. 수정 1회 | 요구사항 범위 안의 수정 요청 접수 → 반영 → 재검수(5단계 반복) → 재전달 | 요청 수령 후 24시간 이내 | 수정본 전달 완료 |
| 8. 완료 처리 | 완료 안내 발송, 구매확정 요청. 제작 이력(요구사항·산출물·소요 시간)을 내부 기록에 남김 | 수정본 전달 후 | 주문 종료 |

**운영 원칙**
- 납기(24~48시간)는 결제 시점이 아니라 **요구사항 5개 항목 답변을 받은 시점**부터 셉니다. 상세페이지와 안내문에 같은 문장으로 적어 분쟁을 막습니다.
- 고객이 요구사항을 회신하지 않으면 제작을 시작할 수 없습니다. 24시간·72시간에 한 번씩 안내하고, 7일간 회신이 없으면 상황을 안내한 뒤 환불 또는 대기 연장 중 선택하시게 합니다.
- 검수(5단계)를 건너뛰고 전달하지 않습니다. 오류가 남은 파일은 수정 1회를 소모시켜 고객 손해로 이어집니다.
- 고객이 보낸 참고 파일에 개인정보나 거래처 정보가 들어 있으면 제작에 필요한 범위에서만 쓰고, 완료 처리 후에는 작업 사본을 지웁니다.

### 5-B. 주문 옵션 구성안

**단일 옵션으로 등록합니다.** 옵션을 여러 개 열어 두면 고객이 범위를 스스로 판정해야 해서 분쟁이 생깁니다.

|---|---|---|
| 기본형 (단일 옵션) | ₩39,000 | 시트 3개 이내 / 입력 항목 20열 이내 / 자동 계산 항목 10개 이내 / 사용법 안내 시트 / 수정 1회 |

**기본형을 넘는 요청(복잡형) 처리 방식** — 옵션에 미리 노출하지 않고, 요구사항을 받은 뒤 개별 안내합니다.

1. 3단계(범위 판정)에서 초과 사유와 추가 금액을 톡톡으로 안내합니다. 예: "말씀하신 거래처별 집계와 월 마감 시트가 더해지면 기본형 범위를 넘습니다. 추가 제작비 ₩20,000이 발생합니다. 진행할까요?"
2. 동의하시면 스토어에 올려 둔 **추가 제작비 상품**(₩10,000 단위, 필요한 수량만큼 구매)으로 결제하시게 안내합니다.
3. 동의하지 않으시면 기본형 범위로 줄여 제작하거나, 원하시면 전액 환불합니다. 답변 없이 임의로 축소 제작하지 않습니다.
