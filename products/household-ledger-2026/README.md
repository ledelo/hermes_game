# 2026-2027 자동 가계부 (엑셀)

**파일**: `가계부_2026-2027.xlsx` · **판매가(안)**: ₩5,900 · **원가**: 0원
**대상**: 가계부를 앱 대신 엑셀로 직접 관리하고 싶은 일반 사용자

## 상품 소개 (상세페이지 카피 초안)

"쓰기만 하세요. 계산은 엑셀이 합니다."
지출과 수입을 한 줄씩 적기만 하면 24개월치 월별 집계와 예산 대비 분석이 자동으로 계산되는 엑셀 가계부입니다.
설정 시트에서 내 카테고리와 월 예산을 정해두면, 대시보드에서 2026년 1월부터 2027년 12월까지 수입·지출·저축액·예산 소진율이 한눈에 보입니다.
카테고리분석 시트는 조회월 한 칸만 바꾸면 그 달에 어떤 항목에서 예산을 초과했는지 "초과 / 양호"로 바로 알려줍니다.
매크로 없이 순수 엑셀 수식으로만 만들어 보안 경고 없이 열리고, 엑셀 2010 이상이면 어디서나 그대로 동작합니다.

- 지출 500행 / 수입 200행 서식·집계 범위 내장
- 카테고리 12종, 이름과 예산을 사용자가 직접 수정 → 전 시트 자동 반영
- 카테고리·결제수단 드롭다운 내장 (오타로 인한 집계 누락 방지)
- 색상 규칙으로 입력 칸과 자동 계산 칸을 구분 (파란 글씨 = 입력, 노란 배경 = 필수)

## 시트 구성 (6개)

|---|---|---|

| **설정** | 월 예산 총액 / 카테고리 12종의 이름·월 예산·비중 / 결제수단 목록. 카테고리 목록을 관리하는 유일한 시트 | 17 |

**설계 규칙**
- 계산은 전부 엑셀 수식. 파이썬으로 계산한 값을 써넣은 셀은 없음.
- 사용 함수는 `SUM` / `SUMIFS` / `IF` / `EDATE` 4종 (전부 Excel 2007 표준). `XLOOKUP`·`FILTER`·`TEXTJOIN`·`IFS` 등 신함수 미사용.
- 월별 집계는 `SUMIFS` + `EDATE` 날짜 구간 방식 (`">="&기준월`, `"<"&EDATE(기준월,1)`) — 보조 열 없이 동작.
- 대시보드 A열은 시작 월 한 칸만 값이고 나머지 23개월은 `=EDATE(직전월,1)` 로 이어짐. 시작 월을 바꾸면 24개월 전체가 따라 이동.
- 수식 열은 `=IF($A4="","",...)` / `=IF($C7=0,"",...)` 빈 행·0 나누기 가드 적용.
- 서식: 금액 `#,##0"원"`, 비율 `0.0%`(분수 저장), 날짜 `yyyy-mm-dd` / `yyyy-mm`. 전체 폰트 Malgun Gothic.
- 색상: 입력 셀 파란 글씨(0000FF), 필수 입력 노란 배경(FFFF00), 수식 검정, 헤더 흰 글씨 + 남색 배경(1F4E79).
- 시트명에 공백 없음 (시트 간 참조 시 따옴표 불필요).

**4. 분기·필터링 동작 검증 (임시 사본으로 실행, 배포본 미변경)**
- 식비에 600,000원 추가 입력 → 지출 687,400원(예산 600,000원 초과) → 상태 칸 `양호` → **`초과`** 로 전환, 잔여 예산 −87,400원. IF 분기 정상.
- 2026-09 지출 111,111원 추가 → 2026-09 행에만 반영되고 2026-08 행은 불변. SUMIFS 월 구간 필터링 정상.

**5. 정적 감사**
- 사용 함수 `EDATE / IF / SUM / SUMIFS` — 허용 목록 외 0건, 금지 함수 0건, LibreOffice 파싱 실패(소문자화) 수식 0건.
- 폰트: 전 셀 Malgun Gothic (4,179셀 / 타 폰트 0).
- 드롭다운(이름 정의 `카테고리목록`, `결제수단목록`) 재계산 후에도 유지 확인.
- 전 XML 파트 well-formed 확인 후, 패치본을 LibreOffice로 재개봉하여 245수식·0오류 재확인.

**참고 — 폰트 후처리**: 컨테이너에 Malgun Gothic이 없어 `recalc.py`(LibreOffice)가 저장 시 폰트를 `WenQuanYi Zen Hei`로 대체하고 문자열을 rich-text run으로 분할한다. 재계산 이후 `xl/styles.xml`·`xl/sharedStrings.xml`·`xl/theme/theme1.xml`만 패치해 Malgun Gothic으로 원복했다(워크시트의 수식·캐시값은 미변경). **이 파일을 다시 `recalc.py`로 돌리면 폰트가 재대체되므로, 재계산 시 폰트 원복 후처리를 반드시 다시 적용해야 한다.**

## 남은 이슈

- 조건부 서식은 요구사항대로 미사용 (초과 여부는 IF 텍스트로 표시).
- 조회월은 그 달의 1일 날짜로 입력해야 함 (화면에는 `yyyy-mm`으로 표시). 사용법·조회월 옆 안내 문구로 커버.
- 카테고리는 12개 고정. 13개 이상이 필요하면 행 삽입과 수식 확장이 필요.
