# 추석 선물·예산 플래너 (엑셀)

**파일**: `추석_선물예산_플래너.xlsx` · **판매가(안)**: ₩3,900 · **원가**: 0원
**대상**: 추석 선물과 차례·장보기 예산을 한곳에서 관리하려는 일반 사용자

## 상품 소개 (상세페이지 카피 초안)

"선물은 다 돌렸는데, 이번 추석에 대체 얼마 썼지?"

추석 지출은 한 번에 나가지 않습니다. 부모님 선물, 조카 용돈, 직장 선물, 차례상 장보기,
기름값이 2주에 걸쳐 흩어져 나가니 다 끝나고 나서야 총액을 알게 됩니다.

이 엑셀은 **정한 예산과 실제로 쓴 돈을 나란히 보여주는** 서식입니다.
선물은 [선물리스트]에 한 줄씩, 장볼 것은 [장보기체크]에 한 줄씩 적으면
[대시보드]가 분류별 지출·잔여 예산·그룹별 지출·진행률을 자동으로 계산합니다.

- **예산 대비 지출이 한 화면에** — 선물 / 차례·장보기 / 여행·교통 세 분류의 예산, 지출, 잔여 예산, 집행률이 한 표에 나옵니다. 잔여가 음수면 넘긴 것입니다.
- **누구한테 얼마 썼는지** — 부모님·형제자매·친척·직장 등 대상 그룹 8개별로 건수와 지출이 자동 집계됩니다. 그룹 이름은 내 가족 구성에 맞게 바꿀 수 있습니다.
- **아직 안 산 것만 보입니다** — 상태(계획/주문/완료)별 건수가 나오고, 선물 진행률과 장보기 진행률, 둘을 합친 전체 준비 진행률이 자동으로 계산됩니다.
- **얼마나 아꼈는지** — 예상 가격과 실제 구매가를 둘 다 적으면 줄마다 절약액이 자동 계산되고, 그룹별로도 합산됩니다.
- **2026년 추석 날짜 반영** — [연휴일정] 시트에 2026년 추석 당일(9/25 금)과 연휴 기간(9/24~9/26)을 확인해 적어 두었습니다.
- 선물 100줄 · 장보기 80줄 · 일정 30줄 · 매크로 없는 순수 엑셀 수식 파일 (보안 경고 없이 열림)

**과장 없이 밝혀두는 범위**

- 가격을 자동으로 가져오거나 쇼핑몰과 연동되는 기능은 없습니다. **수기 입력 서식**입니다.
- 선물 예산 900,000원 / 차례·장보기 500,000원 / 여행·교통 300,000원은 **자리를 채워 둔 초기값**일 뿐, 권장 금액이 아닙니다. [설정] 시트에서 본인 예산으로 바꿔서 쓰는 값입니다.
- 여행·교통 분류는 지출 입력 시트가 따로 없습니다. 교통비·숙박비 합계를 [설정] 시트에 **직접 한 줄로 적는 방식**입니다.
- 차트·그래프는 없습니다. 숫자 표로만 보여줍니다.
- [연휴일정] 시트에 적어 둔 날짜는 **2026년 기준**입니다. 추석은 음력 8월 15일이라 해마다 양력 날짜가 다르므로, 다른 해에 쓰실 때는 달력을 확인하고 고쳐 쓰셔야 합니다.

### 대시보드 계산식

```
선물 지출          = SUM(선물리스트 실제 구매가)
차례·장보기 지출    = SUM(장보기체크 실제 가격)
여행·교통 지출      = 설정 시트에 직접 적은 금액
잔여 예산          = 예산 − 지출
집행률             = 지출 ÷ 예산            (IFERROR 로 0 나눗셈 방어)

절약액(줄)         = 예상 가격 − 실제 구매가
                     단, 선물 품목·예상 가격·실제 구매가 중 하나라도 비면 빈칸

그룹별 건수        = COUNTIFS(선물리스트 대상 그룹, 그룹명)
그룹별 예상/실제/절약 = SUMIFS(해당 열, 선물리스트 대상 그룹, 그룹명)
상태별 건수        = COUNTIFS(선물리스트 상태, 상태명)
상태별 예상/실제    = SUMIFS(해당 열, 선물리스트 상태, 상태명)

선물 전체 건수      = COUNTIF(선물리스트 선물 품목, "<>")
장보기 전체 건수    = COUNTIF(장보기체크 품목, "<>")
장보기 완료 건수    = COUNTIF(장보기체크 구매 완료, "O")
선물 진행률        = 선물 완료 건수 ÷ 선물 전체 건수
장보기 진행률      = 장보기 완료 건수 ÷ 장보기 전체 건수
전체 준비 진행률    = (선물 완료 + 장보기 완료) ÷ (선물 전체 + 장보기 전체)
```

### 설계 규칙

- 계산은 전부 엑셀 수식. **파이썬으로 계산한 값을 써넣은 셀은 0개** — 대시보드에는 숫자 리터럴이 하나도 없고 전부 수식입니다 (실측 확인).
- **사용 함수 6종**: `SUM` `SUMIFS` `COUNTIF` `COUNTIFS` `IF` `IFERROR` — 전부 Excel 2007 표준.
  `XLOOKUP` `FILTER` `SORT` `UNIQUE` `TEXTJOIN` `IFS` `SWITCH` `INDEX` `MATCH` `SUMPRODUCT` `COUNTA` `VLOOKUP` 등 미사용 (자동 검사 통과).
- **빈 행 가드**: 절약액은 `=IF($C5="","",IF($D5="","",IF($E5="","",$D5-$E5)))` 3중 가드.
  대시보드의 그룹별·상태별 집계는 항목명이 비면 계산하지 않는 `=IF($A11="","",...)` 가드.
- **항목명은 전부 설정 시트를 참조** — 대상 그룹명(`설정!$A$14:$A$21`), 상태명(`설정!$B$14:$B$16`), 예산 분류명(`설정!$A$5:$A$7`)을 대시보드가 그대로 읽어 옵니다. 설정에서 이름을 바꾸면 드롭다운과 집계 항목이 함께 따라갑니다.
- **드롭다운 4개**는 이름 정의를 씁니다: `대상그룹목록` `상태목록` `장보기분류`, 그리고 구매 완료용 `"O"` 고정 목록.
- **서식**: 폰트 전체 `Malgun Gothic`. 입력 칸 파란 글씨(`0000FF`), 필수 칸 노란 배경(`FFFF00`), 수식 검정(`000000`), 머리글 흰 글씨 + 남색 배경(`1F4E79`), 예시 행 회색 배경(`F2F2F2`). 원화 `#,##0"원"`, 비율 `0.0%`, 건수 `#,##0"건"`.
- **시트명에 공백 없음** (6개 전부).
- 예시 데이터는 선물리스트 5·6행, 장보기체크 5·6행. 각 시트의 6행은 실제 가격을 일부러 비워 두어 **빈 행 가드가 동작하는 모습**을 보여줍니다.
