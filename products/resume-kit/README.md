- 예시 내용은 「홍길동 / ○○대학교 / △△주식회사 / □□주식회사」 더미이며 실존 회사·학교명을 쓰지 않았습니다.

## 남은 이슈 · 정직 노트

- **렌더 확인은 LibreOffice 기준입니다.** 이 컨테이너에는 맑은 고딕이 없어 변환 시 나눔 계열로 대체되어 표시되었습니다. 글자 폭이 달라 MS Word에서는 줄바꿈이 한두 곳 다를 수 있습니다. 다만 표 폭·행 높이·여백은 DXA 고정값이라 배치는 같습니다. 맑은 고딕이 설치된 실기에서 한 번 더 열어 보는 편이 안전합니다.
- 자기소개서 답변 상자의 행 높이는 `EXACT`가 아니라 `ATLEAST`입니다. 구매자가 권장 분량보다 길게 쓰면 상자가 늘어나며 쪽수가 자연히 늘어납니다(내용이 잘리지 않도록 의도한 설정입니다).
- 사진 칸은 이미지가 아니라 안내 글자가 들어간 빈 표 칸입니다. 구매자가 직접 사진을 넣습니다(방법은 사용가이드 4번).
- 컨테이너 환경 메모: `dpkg -l libreoffice-writer`가 미설치(`un`) 상태에서도 종료 코드 0을 돌려주어 설치 여부 판정에 쓸 수 없었습니다. 실제로는 Writer 모듈이 없어 첫 변환이 `source file could not be loaded`로 실패했고, `apt-get install -y libreoffice-writer` 후 정상 변환되었습니다. 다음 문서 작업 때는 `dpkg -l libreoffice-writer | grep -q '^ii'`로 확인하는 편이 정확합니다.
- 판매 채널 등록은 스토어 연동 후에 가능합니다. 위 등록 문안은 연동 시점에 그대로 쓸 수 있게 준비해 둔 초안입니다.
