## 모델 라우팅 (2026-08-13 사용자 지시)
- **기획·설계·검수·커밋 = Fable(메인 허브)**: 파이프라인 설계, 상품 선정, 우선순위 판단, 서브에이전트 산출물 검수, git 커밋/푸시, 사용자 보고.
- **실행 작업 = Opus 서브에이전트** (Agent 도구, model: "opus", 백그라운드): 엑셀/문서 제작, 웹툴 코딩, 대량 데이터 가공 등 BUILD 큐의 손작업. 서브에이전트는 커밋하지 않는다 — 산출물+자가검증 결과를 보고하면 Fable이 검수 후 커밋.
- 검수 기준: 수식 재계산(recalc.py) 통과, 가드레일 위반 없음, 실제로 쓸만한 품질(스스로 돈 주고 살 물건인가).

## 환경 노트
- **LibreOffice**: 컨테이너에 기본으로 `libreoffice-calc`가 없어 recalc가 행에 걸림. 컨테이너 재생성 후 첫 엑셀 작업 전에 `dpkg -l libreoffice-calc || (apt-get update && apt-get install -y libreoffice-calc)` 실행할 것. 설치 불가 시 정적 린트 폴백 + README에 명시.
- **폰트 함정**: 컨테이너에 Malgun Gothic이 없어 recalc.py(LibreOffice 저장)가 폰트를 WenQuanYi로 대체하고 문자열을 rich-text run으로 쪼갬. **재계산 후 반드시 `tools/fix_fonts.py`로 원복**할 것 (styles/sharedStrings/theme만 zip 패치, 수식·캐시값 불변).

## Track D — 사용자 5분 무료 액션 대기 목록 (각각 새 수익 레일)
1. **네이버 스토어 연동** ← 매출의 문. leviosa.ai.kr → Settings → Naver → 커넥터 새로고침
2. 쿠팡 WING OPEN API 키 발급 → Leviosa 등록 (제2 판매 채널, 무료)
3. 토스/카카오페이 송금 링크 1개 → 웹툴에 후원 버튼 부착 (무료)
4. **네이버 검색광고 계정 + API 키 (무료)** → 키워드별 **월간 검색량 실측** 확보. 현재 수요 판단은 트렌드 기사 수준인데, 이게 열리면 검색량 기반으로 상품 선정 정밀도가 한 단계 올라감 (searchad.naver.com 가입 → 도구 > API 사용 관리)
- 원칙: 여기 항목은 알림으로만 안내, 진행은 절대 블로킹하지 않음.
