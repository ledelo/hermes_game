## 모델 라우팅 (2026-08-13 사용자 지시)
- **기획·설계·검수·커밋 = Fable(메인 허브)**: 파이프라인 설계, 상품 선정, 우선순위 판단, 서브에이전트 산출물 검수, git 커밋/푸시, 사용자 보고.
- **실행 작업 = Opus 서브에이전트** (Agent 도구, model: "opus", 백그라운드): 엑셀/문서 제작, 웹툴 코딩, 대량 데이터 가공 등 BUILD 큐의 손작업. 서브에이전트는 **git 명령(add/commit/push) 실행 자체가 금지**다(2026-08-13 위반 사례 `0fd1dfe` 이후 명문화) — 산출물+자가검증 결과만 보고하면 Fable이 검수 후 커밋. HUB/큐 문서의 상태 표기(DONE 등)도 허브 전권. 스폰 프롬프트에 이 금지를 반드시 명시할 것.
- 검수 기준: 수식 재계산(recalc.py) 통과, 가드레일 위반 없음, 실제로 쓸만한 품질(스스로 돈 주고 살 물건인가).
- **3단 모델 라우팅 (2026-08-14 사용자 지시 확정)**:
  - **Sonnet** = 가벼운·중간 실무: 리서치 호출·결과 정리, 배치 실사 파싱, 재고 감사 스윕, 정형 데이터 가공 (Agent 도구 model:"sonnet"으로 위임)
  - **Opus** = 실행·고난도 코딩: 상품 제작(엑셀/문서/PDF), 웹툴 개발, 복잡한 자동화 스크립트
  - **Fable** = 기획·파이프라인 설계·검수·자금이 걸린 판단(등록/주문수락/클레임 결정)·사용자 보고
  - 구조 제약(정직 기록): 세션 고정 모델은 내부에서 변경 불가 — **사용자가 UI 모델 선택기로 Sonnet 전환 시 역전 아키텍처 발효**: 허브 틱 = Sonnet(반복 실무·커밋), 실행·코딩 = Opus 서브에이전트, **고난이도 설계·애매한 자금 판단 = Fable 서브에이전트 상향 위임** (Agent model:"fable"). Fable 상향 위임 기준: 플레이북에 명시 규칙이 없는 판단(신규 카테고리 리스크, 클레임 예외 케이스, 가격 전략 변경, 파이프라인 재설계)만. 명시 규칙이 있는 동작(프로브, SLA 내 주문 수락, READY 목록 등록, 정산 기록)은 Sonnet이 플레이북 문언대로 직접 수행. 웨이크 빈도: 대기 중 2시간, 연동 시 매시간 복원(cron '0 * * * *').

## 환경 노트
- **API 529 (Overloaded)**: Anthropic 서버 과부하로 틱 턴 자체가 죽는 경우가 있음 (2026-08-13 심야 2회 관측). 시스템 영향 없음 — 상태는 git에 있고 다음 틱이 자동 이어받음. 유실 틱의 리서치/프로브는 다음 정상 틱에서 만회. 사용자 조치 불요.
- **LibreOffice**: 컨테이너 기본 이미지에 calc/writer 모듈이 없음(core만). 모듈 확인은 반드시 `dpkg -l <pkg> | grep -q '^ii'` 형태로 — `dpkg -l`은 미설치(un)여도 종료코드 0이라 오탐함(2026-08-13 이력서 에이전트 발견). 엑셀 작업 전 libreoffice-calc, docx 검증 전 libreoffice-writer 설치. 설치 불가 시 정적 린트 폴백 + README 명시.
- **폰트 함정**: 컨테이너에 Malgun Gothic이 없어 recalc.py(LibreOffice 저장)가 폰트를 WenQuanYi로 대체하고 문자열을 rich-text run으로 쪼갬. **재계산 후 반드시 `tools/fix_fonts.py`로 원복**할 것 (styles/sharedStrings/theme만 zip 패치, 수식·캐시값 불변).
- **바이너리 업로드 불가**: Drive MCP create_file은 인라인 base64만 받는데, LLM 토큰 스트림의 base64 재현은 ~6KB부터 무성 손상됨(2026-08-13 실측: 9,140자 탈락, md5 불일치). rclone/서비스계정도 없음. **에이전트/허브의 바이너리 업로드 시도 금지** — 전달 인프라는 사용자 수동 업로드(Track D #5) 또는 자격증명 제공 후에만. Drive MCP는 삭제 도구가 없어 손상 파일이 영구 잔류하니 검증 없는 업로드 절대 금지.
