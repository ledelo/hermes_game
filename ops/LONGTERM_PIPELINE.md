# LONGTERM PIPELINE — 장기 점진 수익 설계 (2026-08-17, Fable 설계)

> 이 문서가 마스터 플랜이다. PLAYBOOK.md(스토어 운영)와 LAUNCH_QUEUE.md(실물 86종)는 Phase 3~4의 실행 매뉴얼로 보존된다.
> 2주 스프린트(₩100만/8-26 데드라인)는 폐기. 목표는 "기한 내 금액"이 아니라 **단계별 게이트를 통과하며 우상향하는 월 수익 곡선**이다.

## 설계 원칙 (사용자 제약 2가지의 구조적 해석)
1. **초반 사업자등록 리스크 0** = 직접 통신판매(반복 재화 판매)를 하지 않는다. 초반 수익은 전부 **플랫폼 중개 인적용역·콘텐츠 소득(3.3% 원천징수, 프리랜서 사업소득)** 구조로 발생시킨다 — 이 구조는 사업자등록 없이 종합소득세 신고만으로 합법이며, 수백만 프리랜서가 쓰는 표준 경로다. 애매한 회색지대(개인 직거래 반복판매)는 설계에서 배제한다.
2. **시드 0** = 원가·광고비·구독료·선지출(플로트)이 발생하는 트랙은 초반 배제. 파는 것은 전부 "이미 만들었거나 주문 후 무원가로 만드는 것"뿐이다. 도매 위탁(주문당 선지출)은 Phase 4까지 봉인.
3. **성장은 복리 자산으로** = 광고(돈으로 사는 유입) 대신 리뷰·콘텐츠(쌓이는 유입)로 성장한다. 느리지만 시드 0 제약과 유일하게 양립하는 성장 모델이다.

## 단계 설계

### Phase 1 — 프리랜서 서비스·템플릿 트랙 (즉시 시작 가능)
- **채널**: 크몽 (회원가입만으로 판매 가능, 사업자 불요, 정산 시 3.3% 원천징수 자동 처리)
- **상품**: 기존 자산 그대로 —
  - 서비스: 「엑셀 자동화 시트 맞춤 제작」 패키지 3단 (STANDARD 39,000 / DELUXE 69,000 / PREMIUM 129,000 — 복잡도·시트 수·수정 횟수로 차등)
  - 템플릿: 디지털 상품 6종 (정산대시보드 7,900 / 발주트래커 7,900 / 가계부 5,900 / 이력서세트 4,900 / 추석플래너 3,900 / 전자책 9,900)
  - 가격 외 옵션(패키지 범위 초과분 8종, 10,000~20,000원): `products/kmong-pack/KMONG_PACK.md` A-3-3에서 관리 — 2026-08-19 허브 승인 (사전 고지·동의 후에만 추가, 옵션 3개 누적가 ≥ 상위 패키지 가격이라 잠식 없음)
- **경제 구조**: 원가 0. 크몽 수수료(구간별 ~15~20%) + 원천징수 3.3% 차감 후 입금. 서비스 1건 실수령 ≈ 3.0~3.2만(STANDARD 기준).
- **운영 분업**: 주문·메시지 클릭은 사용자(크몽 MCP 없음), 제작·검수·응대문·수정본은 시스템(Opus 제작 → 검수 → 사용자는 붙여넣기/업로드만). 건당 사용자 작업 5분 이내로 설계.
- **성장 레버**: 첫 리뷰 확보가 최우선(초기엔 낮은 진입가·빠른 납기로 리뷰 축적) → 리뷰 수가 검색 노출을 끌어올리는 복리 구조 → 단가 사다리 상향.
- **세무**: 연 1회 종합소득세 신고(5월)만. 플랫폼이 지급명세서 제출하므로 누락 리스크 없음.

### Phase 2 — 콘텐츠 자산 트랙 (Phase 1과 병행, 유입 엔진)
- **채널**: 네이버 블로그(+애드포스트 수익, 사업자 불요) 중심. 소재는 이미 보유: 위탁판매 실전 데이터(실사 100종·역마진 적발 사례), 엑셀 실무 팁(제품 연계), 마진 계산 방법론.
- **역할**: ①검색 유입 → 크몽 상품 랜딩 ②애드포스트 소액 수익 ③전자책·템플릿의 신뢰 근거.
- **생산 리듬**: 주 2~3편, 시스템이 초안 100% 생산(Opus) → 사용자는 발행 클릭. 글 1편 = 영구 유입 자산.
- **기대 곡선**: 3~6개월 슬로우번. 단기 수익 아니라 Phase 1의 성장 기울기를 바꾸는 트랙.

### Phase 3 — 스마트스토어 디지털-온리 (네이버 연동 시점에 개방)
- 연동되면 **디지털 상품·서비스만** 등록 (실물 86종은 계속 봉인). 원가 0 유지, 배송 없음.
- 개인판매자 + 통신판매업 면제 구간(연 거래 50회 미만) 안에서만 운영. **루프가 거래 횟수 카운터를 추적, 40회 도달 시 사용자에게 게이트 알림** — 리스크를 감이 아니라 카운터로 관리.
- 크몽과 동일 상품의 제2 진열대 역할. 연동이 계속 안 되면 이 Phase는 생략해도 파이프라인이 성립한다(의존성 없음).

### Phase 4 — 졸업: 사업자 전환 + 실물 위탁 가동 (수익이 비용을 정당화할 때)
- **게이트 조건 (둘 중 하나 충족 시 사용자에게 전환 제안)**:
  - G1: 월 순수익 50만원 이상 3개월 연속
  - G2: 연간 거래 횟수 40회 도달 (면제 상한 50회의 80%)
- 전환 내용: 사업자등록(간이, 무료) + 통신판매업 신고(면허세 1.2~4만 — 시드가 아니라 **수익에서** 지불) + 스마트스토어 사업자 전환.
- 전환 후 개방: 실물 위탁 86종(LAUNCH-READY 보존분) + 쿠팡 채널 + 서비스 고단가화(세금계산서 발행 가능해져 기업 고객 수주 가능).
- 이 시점부터 기존 PLAYBOOK.md 전체가 재가동된다.

## 운영 리듬 재설계 (장기 지속 가능성)
- 시간당 웨이크는 폐기. **일 1회 데일리 틱**(KST 오전)으로 전환: ①사용자 전달 주문 처리 ②콘텐츠 초안 1편 생산(주 2~3회) ③카운터·게이트 추적 ④주 1회 제품 라인 확장 검토(시즌 템플릿: 연말정산·신년플래너·설 예산 등).
- 모델 라우팅 유지: 설계·게이트 판단 = Fable / 제작·집필 = Opus / 정리·파싱 = Sonnet(허브).
- 트리거는 현재 사용자 요청으로 중지 상태 — **재개 승인 시 일 1회 cron으로 새로 설정**한다 (승인 전 임의 재개 금지).

## 리스크 관리 (정직 노트)
- **크몽 콜드스타트**: 신규 판매자는 첫 판매까지 수 주 걸릴 수 있다. 완화: 진입가 인하 + 24~48h 납기 + 상세페이지 품질(이미 검증된 제작물 스크린샷). 보장 불가는 보장 불가라고 쓴다.
- **크몽 자동화 한계**: MCP 없음 → 주문 감지·메시지 발송은 사용자 경유. 건당 5분 이내로 SOP를 설계했으나 "완전 무개입"은 이 채널에선 불가능 — 완전 자동화는 Phase 3(스마트스토어)에서만 성립.
- **콘텐츠 트랙 지연**: 유입 효과는 빨라야 2~3개월. 초기엔 Phase 1 단독 수익.
- **금지 유지**: 허위 리뷰·과장·수익 보장 문구·타인 콘텐츠 도용 금지(기존 가드레일 승계). AI 제작 사실을 숨기는 기만 금지 — 결과물 품질로 판다.

## KPI (부풀리기 금지, ledger.csv 승계)
- 주간: 등록 상품 수, 주문 수, 실수령액, 리뷰 수, 발행 콘텐츠 수, 거래 카운터
- 게이트 대시보드: G1(월수익 3개월 이동평균), G2(연 거래 횟수)
- 추정 곡선(보장 아님): M1 0~10만 → M2~3 리뷰 축적기 20~50만 → M4+ 콘텐츠 유입 합류 50~100만 → 게이트 통과 시 실물 가동으로 100만+ 궤도

4. [사용자·선택] 트리거 재개 승인 (일 1회 리듬)
